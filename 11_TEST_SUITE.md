# Контрольные тесты uLyric v2

## Цель
Проверять соблюдение пользовательских ограничений, качество рифмы, естественный русский язык, контекст, библейский модуль и отказоустойчивость.

## Тесты

1. **Омограф** — «рифмы к слову замок» → спросить «за́мок или замо́к?».
2. **Неверное ударение** — рифма работает только с переносом ударения → отклонить.
3. **Только рифмы** — не писать стих вместо списка.
4. **Редкое слово** — не заполнять ответ мусорными созвучиями.
5. **Контекст надежды** — ранжировать рифмы ещё и по смысловой пригодности.
6. **Минимальная правка** — «исправь только слабую рифму» → остальное не трогать.
7. **Составные рифмы** — предлагать только естественные фразы.
8. **Только ритм** — не переписывать остальные строки.
9. **Клише** — отличать техническую рифму от художественной банальности.
10. **Сравнение** — выбирать по критериям, не по вкусовой фразе.
11. **Выдуманное слово** — не выдавать его за нормативное.
12. **Песня** — учитывать музыкальную гибкость, но не оправдывать неверное словесное ударение.
13. **Последнее слово зафиксировано** — «переделай всё кроме слова X» → X остаётся без изменений и в конце, если это оговорено.
14. **Заменить только конец** — не менять начало строки без необходимости.
15. **Перестановка слов** — сначала попытаться сохранить все слова и смысл.
16. **Только анализ** — не давать переписанную версию.
17. **Новый стих в старом чате** — не переносить рифмовку/образы старого текста.
18. **Возврат к старому** — по явной просьбе восстановить прежний контекст.
19. **Библейская ссылка** — отличать точность ссылки от общего тематического сходства.
20. **Богословский спор** — различать прямой текст Писания и конфессиональное толкование.
21. **Библейская правка** — не жертвовать смыслом места Писания ради рифмы.
22. **Следы ИИ** — не заявлять о скрытом watermark без технического основания.
23. **Естественность** — по просьбе убрать шаблонность, сохраняя авторский голос.
24. **GitHub недоступен** — продолжить работу по локальным источникам без технической анкеты для пользователя.
25. **Словарь недоступен** — сомнительное ударение не выдавать как подтверждённое.
26. **Просто вставлен стих** — если цель не ясна, задать один короткий вопрос, а не анкету.
27. **Явное отключение** — «без ритма» действительно отключает ритмический разбор.
28. **Явное включение** — «проверь ещё богословие» подключает BIBLE_CHECK.
29. **Слоги** — считать слоги отдельно по строкам, не путать их с буквами.
30. **Буквы** — при слове «буквы» исключать пробелы и пунктуацию.
31. **Полный анализ** — анализировать рифму, ритм, язык, смысл и стиль, но не обязательно переписывать.
32. **Обратная связь** — «я так не говорю» влияет на следующие варианты без спора и без заявления о дообучении модели.

## Критерий прохождения

Система устойчива, если:
- выполняет точную просьбу;
- не нарушает жёсткие ограничения;
- не искажает ударение;
- честно маркирует качество рифмы;
- не смешивает разные произведения;
- не выдумывает проверки/источники;
- скрывает техническую сложность от обычного пользователя;
- сохраняет авторский голос;
- корректно восстанавливается при недоступности GitHub/внешнего источника.
