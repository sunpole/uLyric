# Рифмы и стихи — комплект проектных инструкций

Этот комплект предназначен для работы ChatGPT в проекте, связанном с русскими стихами, рифмами и песенными текстами.

## Что это такое

Это не «дообучение модели» в техническом смысле. Это набор постоянных инструкций, ролей и проверок, которые задают модели обязательный порядок работы.

Главная идея:

**не один универсальный «поэт», а несколько специализированных ролей, каждая из которых проверяет свою часть задачи.**

## Состав

1. `AGENTS.md` — главный файл маршрутизации. Его желательно закрепить как основной регламент проекта.
2. `01_PROJECT_SYSTEM.md` — общие правила проекта.
3. `02_ORCHESTRATOR_AGENT.md` — диспетчер: определяет, какие роли должны участвовать.
4. `03_RHYME_AGENT.md` — подбор и проверка рифм.
5. `04_RHYTHM_METER_AGENT.md` — ритм, слоги, ударения, стихотворный размер.
6. `05_SEMANTIC_STYLE_AGENT.md` — смысл, образность, стилистика, логика.
7. `06_LINE_CONSTRUCTOR_AGENT.md` — построение строк под заданную рифму, смысл и ритм.
8. `07_POETIC_EDITOR_AGENT.md` — редактор стихотворения.
9. `08_QA_CRITIC_AGENT.md` — независимая финальная проверка.
10. `09_SCORING_RUBRIC.md` — единая шкала оценки.
11. `10_OUTPUT_TEMPLATES.md` — стандартные форматы ответов.

## Обязательный принцип

Каждая задача проходит через нужные специализированные роли.

Нельзя выдавать пользователю рифму, строку или отредактированный фрагмент только потому, что «так звучит нормально». Результат должен пройти проверку по фонетике, ударению, смыслу и, когда применимо, ритму.

## Рекомендуемая установка в проекте

Если проект позволяет закреплять файлы, закрепить все документы.

Если есть отдельное поле «Инструкции проекта», поместить туда содержание `AGENTS.md` и `01_PROJECT_SYSTEM.md`.

Остальные документы использовать как обязательные справочные регламенты.

## Язык

По умолчанию работа ведётся на русском языке.

Если пользователь не просил другой язык, не переходить на другой язык самовольно.
